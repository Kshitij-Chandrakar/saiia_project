Array Pair Sum

Problem

Given an array of integers and a target value, return the indices of two numbers whose sum equals the target.

Input Format

The first line contains n. The second line contains n integers. The third line contains target.

Output Format

Print two zero-based indices separated by a space.

Constraints

  • 2 <= n <= 100000
  • Each input has exactly one valid pair.

Example

Input: 4 2 7 11 15 9

Output: 0 1

Explanation: 2 + 7 equals 9.
