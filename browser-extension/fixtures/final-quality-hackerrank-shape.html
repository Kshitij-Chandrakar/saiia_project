Merge the Tools!

Task

Given a string and an integer, split the string into parts and print each unique subsequence.

Input Format

The first line contains a string. The second line contains an integer.

Prints

Print each subsequence on a new line.

Constraints

  • 1 <= length of string <= 10^4
  • 1 <= k <= length of string

Sample Input

STDINFunction
AAABCADDEs = "AAABCADDE"
3k = 3

Sample Output

AB
CA
DE

Explanation

The string is split into equal parts and duplicate characters are removed from each part.
