Triplet Zero

Given an integer array nums, return all triplets whose sum is zero.

Example 1

Input

nums = [-1,0,1]

Output

[[-1,0,1]]

Explanation

The values sum to zero.

Example 2

Input

nums = [0,1,1]

Output

[]

Explanation

No valid triplet exists.

Example 3

Input

nums = [0,0,0]

Output

[[0,0,0]]

Explanation

All values can be used.

class Solution { vector<int> threeSum(vector<int>& nums) {} };
