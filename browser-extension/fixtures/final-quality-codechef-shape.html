Chef and Instant Noodles

Problem

Given the number of packets and bowls, calculate how many bowls can be served.

Input Format

The first line contains t. Each test case contains two integers.

Output Format

For each test case, print the answer on a new line.

Constraints

1 <= t <= 1000

Sample 1

Input: 2 3

Output: 6

Explanation

Output: 20
