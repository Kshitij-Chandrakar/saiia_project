Merging Communities

Problem

People live in separate communities. Process queries that merge communities and report the size of a requested community.

Input Format

The first line contains two integers n and q. Each of the next q lines contains a query.

Output Format

Print the size of the community for each report query.

Constraints

  • 1 <= n <= 100000
  • 1 <= q <= 100000

Sample Input

3 6
Q 1
M 1 2

Sample Output

1
2
