Merging Communities

People connect into communities. Track community sizes as merge and query operations arrive.

Input Format

The first line contains two integers n and q.

Constraints

1 <= n <= 100000

1 <= q <= 100000

Output Format

For each query of type Q, print the size of the community.

Sample Input

3 6
Q 1
M 1 2
Q 2

Sample Output

1
2
